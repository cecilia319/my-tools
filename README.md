# my-tools · 个人工具站

中国电信 TeleAgent（星辰超级智能体）生成维护的个人工具集合，发布于 GitHub Pages：
**https://cecilia319.github.io/my-tools/**

## 目录结构

| 路径 | 内容 | 更新频率 |
|---|---|---|
| `index.html` | 站点导航门户 | 改版时手动更新 |
| `stock/` | 投资看盘：投资总控台 / 盯盘作战台 / 股票助手工作台 / 抖音情报看板 | 每交易日 15:30 自动 |
| `ta/` | TA 高校演示物库：学科交互课件（医学/物理/化学/农林/经管法/工科/海洋）+ 校级 Token 运营看板 + 客户场景对应总表 | 按需 |
| `fitness/` | 健身小助手 | 手动 |
| `xiaoyi/` | 学习工具（写作作战室） | 手动 |
| `work/` | 工作台快照 + 周报归档 | 每周同步 |
| `demo/` | TA 生成的交互演示成品（SCARA 机械臂 / 浮力实验 / 簪花） | 静态 |

## 说明

- 全部页面为本地生成的单文件 HTML，双击即开、零外部依赖。
- 投资数据仅为个人研究使用，不构成任何投资建议。
- 站点由 TeleAgent 自动构建与发布。
