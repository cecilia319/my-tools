01背景与目标

1.1 业务背景

  • 政策驱动：文旅部持续推动「智慧旅游」与 AI 大模型应用落地，中国电信提出「大模型 + 行业知识库 + 智能体」的行业赋能路线，需要可展示的标杆场景。
  • 资源禀赋：宁德拥有太姥山（5A）、白水洋鸳鸯溪（5A）双 5A，加上霞浦滩涂摄影、木拱廊桥世界非遗、畲族文化等 19 类特色资源，但资源分散、信息割裂、缺乏统一智能入口。
  • 技术成熟：知识库问答、浏览器定位、地图开放平台、网页自动检索等能力已可组合成低成本、可落地的智能体应用。

核心场景故事

💡 场景 A · 抵达即开讲：游客自驾抵达太姥山，打开手机（扫过主页二维码已在主屏），导游模块定位成功自动开讲；切「专业导游」问「门票多少钱」，回答附联网检索的最新票价与优惠信息。
💡 场景 B · 台式机演示：办公室无 GPS，IP 定位偏移 50km——产品识别低精度仅排序不误讲，用户点「🔧 校准」选太姥山，全站距离、附近查询、路线起点即刻同步，地图蓝点飞至街道级。
💡 场景 C · 拍摄赶潮：摄影游客明早想拍北岐日出，查拍照攻略得知日出时刻与当日高潮时刻，行程规划师把北岐列入首站并给出建议停留时长。

设计原则

  • 两击可达：任一功能从主页 ≤2 次点击可达；子页统一左上「‹ 主页」返回。
  • 生活化文案：口语化、友好（如「没关系喵，在下方搜索景点」），不用技术术语面对用户。
  • 山海清新风：深青绿→翡翠渐变 + 霞光橙点缀 + 水彩背景，贴合宁德山海气质。
  • 降级不恐吓：外部服务故障一律转化为可理解的提示 + 替代路径（如限流 → 提示稍后恢复 + 保留列表）。

04功能需求详述

优先级定义：P0 核心闭环 缺失则产品不成立；P1 重要体验 差异化竞争力；P2 增强 锦上添花。每条需求均含已实现的验收规则。

FR-01🎧 定位与自动讲解P0
作为自由行游客，我希望打开应用就自动知道我在哪个景区，以便不必手动选择就能听讲解。
项需求规格
定位获取进入导游页自动请求浏览器定位，超时 9s；成功后记录坐标与精度值（accuracy）。
开讲规则精度 <5km 且最近景区距离 <20km → 自动开讲该景区；精度 ≥5km（IP 级）仅排序不自动开讲，页面提示「IP 定位，距离仅供参考」。
排行榜有定位按距离升序（首名标「📍 离你最近」）；无定位按热度（5A＞国家级＞其他）；支持名称/区县/标签搜索。
讲解内容景区头图 + 等级徽章 + 距离 + 标签 + 简介 + 核心亮点 + 开放时间（visit_hours）；讲解同步 TTS 朗读（声控开关）。
异常处理定位被拒/失败 → 引导手动校准与手动选择；超时 → 「定位有点慢」过渡文案。
FR-02🔧 手动位置校准P1
作为桌面/台式机用户，我的定位常偏移几十公里，我希望手动告诉系统我在哪，以便距离排序与附近的推荐是真准的。
项需求规格
入口导游页排行榜头部常驻「🔧 校准」按钮；精度 ≥5km 时按钮变为橙色警示态。
校准方式① 搜索地名（本地景区白名单 → POI 搜索 → 地理编码三层回退，限流时提示改选景区）；② 快捷点选 22 个收录景区。
候选展示最多 6 条候选，含名称 + 地址，逐条「📍 用这个」确认。
校准生效写入全局定位态（清空精度值视为可信点），距离排序、附近查询、路线「当前位置」全站同步；地图蓝点即时迁移并挂起飞指令（下次进地图时平滑飞至景区级视野）。
状态提示TOAST + 对话条双重反馈；校准后偏移警示解除。
FR-03💬 问问导游 · 三语气智能问答P0
作为不同风格的游客，我希望选择自己喜欢的问答语气，以便正式场合得到严谨回答、休闲旅行得到亲切陪伴。
项需求规格
三态切换对话区顶部胶囊组：正常 / 专业导游 / 小喵，默认「小喵」；单选高亮（专业导游为橙色系）；切换即生效并有 TOAST 确认。
正常模式客观正式，答案原文直出，无语气词（等同关闭猫娘人格）。
小喵模式猫娘人设：随机开场（如「喵～这个问题小喵最熟啦！」）+ 知识库答案 + 收尾互动语。
专业导游模式① 联网检索最新资讯（无头浏览器抓取搜索摘要，约 6s，前置「🔍 检索中」过渡提示）；② 回答采用持证导游人设（您称谓、开场、分点讲解、祝愿收尾）；③ 附加「——【网上最新参考】」段落并声明以官方公示为准；检索失败静默降级为纯知识库回答，不报错。
LLM 增强设置中配置 OpenAI 兼容 API（星辰大模型）后，实时回答自动按模式注入对应 system 人设；联网材料并入专业模式上下文。
兜底规则知识库未命中：小喵/正常 → 建议换问法或接 LLM；专业 → 表达不确定并建议以景区公示为准（不编造）。
辅助能力建议问题 chips（随当前景区刷新）、回答来源标注（本地知识库/大模型/网络检索）、TTS 朗读。
FR-04🗺️ 地图路线规划P0
作为自驾游客，我希望在一个页面里规划从当前位置到景区的行程，以便不用在多个 App 间来回切换。
项需求规格
出行方式驾车（支持 ≤16 个途经点）/ 公交 / 步行 / 骑行 四种。
地址解析POI 搜索优先 → 地理编码兜底 → 加城市前缀重试；识别「当前位置」占位符；任一环节限流即时中止并提示（不重复请求）。
结果呈现总里程/时长摘要 + 分步导航（每步一条）+ 地图绘制路线；起终点/途经点以文字旗帜标记；公交方案列前 3 个备选。
一键我的位置起点与终点均有「📍 我的位置」按钮：已定位 → 填入并地图平滑飞至街道级（自适应缩放：GPS→16 级、精度渐差逐级拉远至城市级以完整呈现精度圈）；未定位 → 现场触发定位（按钮 loading 态 + 防连点），失败引导校准。
异常处理地址无结果 → 建议换说法（附示例）；接口异常 → 统一降级文案。
FR-05📍 附近查询P0
作为亲子家庭游客，我希望立刻知道附近最近的卫生间/药店/美食，以便及时应对家人需求。
项需求规格
分类与半径8 个分类（卫生间/美食/景点/停车/药店/酒店/加油站/购物）× 4 档半径（1/3/5/10km）。
中心管理默认 = 我的定位或当前讲解景区；支持输入目的地设为自定义中心（橙靶心标记 + 名称标签）、「📍 我的位置」、恢复默认三操作；中心=我的位置时以蓝点呈现（不叠画）。
地图标记查询结果统一「青色小圆点」标记（可点击弹详情）；结果自动 fitView，「我的位置」触发的查询保持街道级视野不回缩；手动换分类后恢复正常 fitView。
美食榜联动美食分类下，POI 命中小红书口碑榜 → 名称挂「🔥榜」角标 + 招牌菜/提及数 + 「口碑榜 →」跳转按钮（P2）。
FR-06🗺️ 地图标记视觉差分体系P1
作为游客，我希望一眼分清地图上哪个是我、哪个是景区、哪些是周边设施，以便快速决策。
标记视觉规格交互
我的位置蓝色脉冲点 + 白描边；精度 >30m 附半透明蓝色精度圈点击显示精度说明与来源（自动定位/手动校准）
收录景区翡翠绿 pin（22 个，尖底朝下）点击弹简介卡 + 「🎧 开始讲解」直达
附近 POI天青色小圆点点击弹名称/地址（含榜单位时显示口碑）
查询中心橙色靶心 + 圆环 + 名称标签点击说明中心语义
路线起终点文字旗帜（🚩起点/🏁终点/📍途经）点击放大确认
FR-07📸 拍照出图攻略（含潮汐）P1
作为摄影爱好者，我希望知道每个机位的最佳时机与当日潮汐，以便一次出片不扑空。
项需求规格
机位攻略热门机位卡片：地理位置、最佳时段、光线建议、穿搭建议；支持地点搜索。
潮汐时刻表年度月相算法推算当日高潮/低潮时刻（四格展示），新月/满月交叉验证误差 <1.5 天；随日期自动更新。
热帖参考小红书近期热帖卡（点赞数 + 标题），数据来自本地更新器（FR-10）。
FR-08🍜 美食榜单P1
作为美食游客，我希望看到真实口碑的本地菜馆而不是广告店，以便吃到地道闽东味。
项需求规格
榜单生成基于小红书笔记提及频次 + 招牌菜提取；伪店名过滤（含「探店/求推荐/合集」等关键词拒绝）。
展示维度店铺名 + 地区/距离 + 招牌菜 + 提及热度；支持地点搜索与 7 档距离筛选（含不限）。
地图联动每店带坐标，可在地图附近查询中被「🔥榜」角标识别（FR-05）。
FR-09🗓️ 行程规划师P1
作为首次到访的游客，我希望能一键得到按区域聚拢的合理排程，以便少走回头路。
项需求规格
规划算法同区县景区聚拢排序，跨区按地理相邻衔接；每站给出真实游玩时长（景区级标注）。
例图示意提供示范行程 + 每站简介；点击站点直达对应讲解页。
FR-10🔄 小红书数据更新P2
作为内容运营者，我希望偶尔一键刷新攻略数据，以便榜单和热帖保持新鲜。
项需求规格
触发方式攻路页「🔄 更新小红书数据」入口卡 → 弹层「开始更新」。
登录流程首次自动弹出浏览器窗口扫码登录（双色校验：cookie + 页面登录态）；登录会话保存在本机（server/xhs-profile/），此后全自动（约 2 分钟）。
可视化进度条 + 百分比 + 阶段时间线（替代日志流）；完成后 TOAST + 数据自动刷新；关闭弹窗后台继续。
质量规则三格式店名提取；xsec_token 校验链路；429 限流降级提示。
FR-11📖 宁德文化专题与节庆P1
项需求规格
文化专题7 大专题（白茶/畲族/廊桥非遗/陈靖姑/红色下党/海洋渔文化/茶盐古道）：图文卡片 + 必体验清单。
节庆日历9 大节庆（三月三/开渔节等）：日期 + 地点 + 可展开观礼贴士。
文化问答知识库文化条目参与问答匹配（FR-03）。
FR-12📱 手机扫码访问 + PWAP2
作为游客，我希望用手机扫一下就能开始用，而不用记住网址。
项需求规格
二维码弹层主页 📱 按钮 → 自研零依赖 QR 生成器（byte 模式/ECC-L/掩码择优 → SVG）渲染 216px 二维码 + URL 明文 + 使用说明。
地址获取后端 /api/lan-ip 实时返回局域网地址（UDP 探测法）；服务绑定 0.0.0.0 允许局域网访问。
说明内容同 Wi-Fi 要求、「添加到主屏幕」指引、防火墙排查提示。
PWAmanifest + 图标 + standalone，添加主屏后无地址栏全屏体验。
FR-13⚙️ 设置与大模型接入P2
项需求规格
