02实验原理反应方程式与突跃概念
总反应
HCl + NaOH = NaCl + H2O
离子方程式：H+ + OH− = H2O（中和反应的本质）

强酸强碱体系 · 精确计算公式（物料守恒）

计量点前：c(H+) = (c0V0 − c1V1) / (V0 + V1)

计量点后：c(OH−) = (c1V1 − c0V0) / (V0 + V1)

计量点时：恰好中和，pH = 7.00（25 ℃）

其中 c0 = 0.1000 mol/L（HCl），V0 = 20.00 mL；c1 = 0.1000 mol/L（NaOH），V1 为滴入体积。

滴定突跃（选择指示剂的依据）

在化学计量点前后 ±0.02 mL（相对误差 ±0.1%）范围内，pH 由 4.3 急剧跃迁至 9.7，变化 5.4 个 pH 单位——这一急剧变化区间称为滴定突跃。

凡变色范围全部或部分落在突跃之内的指示剂（酚酞、甲基橙等）均可用于强酸强碱滴定，终点误差不大于 ±0.1%。

弱酸体系缓冲区使用 Henderson–Hasselbalch 公式：pH = pKa + lg[Ac−]/[HAc]（pKa = 4.74）。

06误差分析（点击展开）实验教学重点 · 3 张折叠卡
① 滴定管读数误差：俯视 / 仰视与估读

滴定管需估读到 0.01 mL（最小分度 0.1 mL 的十分位）。读数时视线必须与凹液面最低处水平相切：

初读数俯视（视线偏高）会使读数偏大、末读数俯视则偏小，综合导致体积偏小、测定结果偏低；仰视相反。装液或滴定结束后应静置约 1 分钟，待内壁液体流下再读数。

对本实验（约 20 mL 用量），±0.01 mL 的读数误差引入的体积相对误差约 ±0.05%，是滴定分析能够保证 ±0.1% 精度的基石。

② 尖嘴气泡与"半滴"操作

气泡：滴定开始前若碱式滴定管尖嘴内留有气泡，滴定后气泡消失，会导致消耗体积虚增、测定结果偏高。操作规范：滴定前挤压玻璃珠排气泡，使尖嘴充满溶液后再调零。

半滴操作：临近终点时，轻挤玻璃珠使液滴悬而不落，用锥形瓶内壁"靠下"这半滴，再用洗瓶以少量蒸馏水冲洗内壁并入瓶中。能否熟练运用半滴操作，直接决定终点能否被卡进 ±0.02 mL 的突跃窗口——这正是"读数精确到 0.01 mL"在操作上的对应物。

③ 指示剂选择差异：甲基橙 vs 酚酞

强酸强碱互滴（突跃 4.3~9.7，范围宽）：甲基橙（3.1~4.4）与酚酞（8.2~10.0）的变色范围均落在突跃之内，两者都可用，终点误差均 ≤0.1%。

强碱滴定弱酸 HAc（突跃仅约 7.7~9.7，范围窄）：计量点产物 NaAc 水解显碱性（pH≈8.7），只能选酚酞；若用甲基橙（3.1~4.4），变色点完全落在突跃之外，终点大幅提前，误差远超允许范围。

指示剂用量以 1~2 滴为宜：过量会使终点颜色过深、本身消耗滴定剂，反而增大误差。

07随堂小测（3 题 · 即答即评）得分：0 / 3
Q1用 0.1000 mol/L NaOH 滴定 0.1000 mol/L HAc（醋酸）时，为什么不宜用甲基橙作指示剂？
解析：弱酸滴定突跃窄且偏碱（计量点 pH≈8.7）。甲基橙变色点在酸性区，远在突跃之外——此时被滴定的 HAc 还大量剩余，终点严重提前，误差远大于 ±0.1%。酚酞变色范围（8.2~10）恰好覆盖突跃，是唯一合适的选择。答案 B。
Q2强碱滴定强酸，计量点前后各半滴（±0.02 mL）内 pH 从 4.3 骤升至 9.7。这一现象说明了什么？
解析：±0.02 mL 内，被滴定组分从过量 0.1% 变为不足 0.1%，c(H+) 骤降约 50 万倍。凡变色范围全部或部分落在突跃内的指示剂（酚酞、甲基橙对强酸强碱体系均可）都能把终点误差控制在 ±0.1% 以内——这正是"突跃"的实用价值。答案 B。
Q3滴定临近终点时，下列操作正确的是？
解析：临近终点必须放慢到半滴半滴地加，每加一滴都充分摇匀；"浅粉色且 30 秒不褪色"用于排除摇动液面冲击与空气中 CO2 溶入造成的暂时变色干扰。颜色过深说明已经滴过量。答案 B。

话术 ① 危险性低的核心实验：课前预演 / 课后复习，药品零消耗

这套虚拟课件让每位学生课前把操作流程、读数规范、终点判断先预演熟练，进实验室一次成功率大幅提高；课后可无限次回放复习——药品零消耗、安全零风险、不限场次。
